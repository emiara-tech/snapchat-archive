# OCCURRENCE-01 stage-2 preflight accepted

Experience prepared the bounded reference/Memory preflight. Root resolved count, proof and supported-field bindings; foundation independently reviewed them against the [producer](../tasks/occurrence-01.md), frozen QUERY/ORDERING contracts and original phases 2/3/5. Both design axes found no actionable defect. Exact type/resource binding remains a precondition before code.

That precondition is now accepted in [the exact binding review](occurrence-01-stage-2-binding.md), with its [literal oracle](../tasks/occurrence-01-stage-2-oracle.md). Implementation and measurement acceptance remain open.

The accepted clarifications are:

- Supported slots retain ordinal gaps. Malformed positions remain exact diagnostics with unknown remainder, rather than guessed historical appearances. Absent, unsupported and known-empty fields remain distinct. Event kind alone does not invent an implicit reference.
- Available media has physical-only source proof. Missing records have actual declaring-row metadata proof and no physical entry. Their ordinary projection keeps only selected occurrence proof and source-backed minimal labels.
- A Saved Media row requires an own established Date, Media Type, Download Link or Location field. Recognized-invalid values preserve a known save with uncertainty; empty/unknown-only objects are diagnostics. Unsupported caption aliases are not promoted, and same-file conflicting timestamp cases retain the same supported date-prefix path.
- Staged facts reuse the accepted occurrence/source/resource DTOs with actual `NormalizedTime`. They cannot claim exact `QueryTime` or complete QUERY capability. Numeric array positions and exact containers survive without claiming textual object-member order.

Before implementation, independently review the author's exact readonly envelope, field names/nullability, reference interpretation, safe parser rules, retained/corrected link-ID literals and file ownership. Freeze incremental count/per-field/aggregate encoded limits covering reference, occurrence, diagnostics and source-registry expansion. Budget failure rejects the whole operation and preserves the reader for retry. Small-limit public tests and actual synthetic expansion measurements are required; policies do not prove heap bounds. The original 100,000-text-event case must remain possible.

No code, tests or runtime measurements are accepted by this preflight. Complete QUERY publication, time/participation, owner-confirmation preparation, layer relations, worker/read lifecycle, FILTER activation and full phases remain open.
